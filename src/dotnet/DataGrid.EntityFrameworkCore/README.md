# DataGrid.EntityFrameworkCore

EF Core integration for [DataGrid](https://github.com/laczynski/DataGrid): `ToGridResultAsync`, `ExportAsync`, and built-in CSV/Excel export.

## Install

```powershell
dotnet add package DataGrid.EntityFrameworkCore
```
