# DataGrid.Core

Query engine for [DataGrid](https://github.com/laczynski/DataGrid): automatic DTO field discovery, filter/sort/search expression building, `IQueryable` extensions, and CSV/Excel export.

## Install

```powershell
dotnet add package DataGrid.Core
```

For EF Core apps, use `DataGrid.EntityFrameworkCore` instead.
